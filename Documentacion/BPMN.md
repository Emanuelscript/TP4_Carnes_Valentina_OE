## Modelo BPMN
## Descripción
El proceso modelado representa el flujo de gestión de inventario de Carnes Valentina.
El sistema registra las ventas realizadas en la carnicería, actualiza automáticamente el stock disponible y verifica si el nivel de existencias alcanzó un valor crítico.
Cuando el stock es insuficiente, el sistema genera una alerta de reposición para el sector ganadero. Posteriormente se coordina el envío de mercadería hacia la carnicería.
